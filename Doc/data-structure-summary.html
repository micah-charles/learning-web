Data Structure Summary

This document explains which JSON or JSONL data structure is currently used by each main feature: Vocabulary, Quiz, Reading, and Builder. It also shows where manifest.json and pack.json fit into the flow.

Last updated: 2026-05-12

Overview

The app is manifest-driven. The browser loads data/generated/manifest.json first, and that file tells each feature which data file to read next.

  • Vocabulary uses dataset vocabPath
  • Quiz uses dataset vocabPath plus optional sentencePath
  • Reading uses passageGroups[*].packs[*].path
  • Builder uses sentenceBuilderPacks[*].path
Important: data/Packs/<pack>/pack.json is mostly metadata for manifest generation. The browser UI does not directly load pack.json at runtime.

Manifest Layer

data/generated/manifest.json is used by all browser features.

Main sections

  • core: default dataset for Vocabulary and Quiz
  • revisionPacks: additional datasets for Vocabulary and Quiz
  • sentenceBuilderPacks: Builder pack registry
  • passageGroups: Reading pack registry

Important fields across these sections include id, displayName, vocabPath, sentencePath, path, fileType, supportsSentences, mergeCoreSentences, stageOptions, and defaultQuizModes.

Vocabulary

Files: data/vocab.json and data/Packs/*/vocab.json

Type: JSON array

Used by: Vocabulary tab, Quiz word questions, Review tab

Core fields in practice: id, de, en, level, topic

Additional fields currently used: part_of_speech or pos, categories, tags, gender, plural, example_de, example_en, accepted_answers, accepted_translations, stage, stage_label

{
  "id": "y7_school_subjects_001",
  "de": "Deutsch",
  "en": "German",
  "pos": "noun",
  "gender": "n",
  "topic": "school",
  "tags": ["Y7", "custom", "topic:school"],
  "level": "Y7",
  "categories": ["school", "vocabulary"],
  "part_of_speech": "noun"
}

Quiz

Files: dataset vocabPath plus dataset sentencePath, with optional core sentence merging

Types: vocab is JSON array, sentence pool is JSONL

Word fields used: id, de, en, topic, level, stage, stage_label, accepted_answers, accepted_translations

Sentence fields used: id, de, en, level, topics, target_vocab_id, vocab_ids

{
  "id": "Y7-SENT-0001",
  "level": "Y7",
  "topics": ["family"],
  "de": "In meiner Familie gibt es fünf Personen.",
  "en": "In my family there are five people."
}
  • supportsSentences: false hides sentence quiz modes
  • mergeCoreSentences: true merges pack sentences with the core GCSE sentence pool
  • defaultQuizModes sets the default quiz mode selection

Reading

Files: data/PassagePacks/**/*.json, with code support for .jsonl too

Types: JSON array, JSON object with top-level passages, or JSONL

Passage fields used: id, chapter, section, title_de, title_en, level, topic, passage_de, passage_en, questions

Question fields used: id, question_en, model_answer_en, optional type, optional difficulty, optional accepted_keywords

{
  "id": "frankfurt_01_flight",
  "chapter": "Frankfurt Trip",
  "section": "The Flight",
  "title_de": "Der Flug",
  "title_en": "The Flight",
  "level": "Y7-Y8",
  "topic": "travel",
  "passage_de": "Der Flug von Sizilien nach Frankfurt dauert zwei Stunden.",
  "passage_en": "The flight from Sicily to Frankfurt takes two hours.",
  "questions": [
    {
      "id": "frankfurt_01_q1",
      "question_en": "How long does the flight take?",
      "model_answer_en": "The flight takes two hours."
    }
  ]
}

Builder

Files: data/SentenceBuilderPacks/*.jsonl

Type: JSONL

Fields used: id, type, prompt, level, answer, tiles

{
  "id": "SR-DATE-0001",
  "type": "key_date",
  "prompt": "331BC",
  "level": "Y7",
  "answer": "The Macedonians defeat the Persians at the battle of Gaugamela",
  "tiles": ["The", "Macedonians", "defeat", "the", "Persians"]
}

Pack Metadata

Files: data/Packs/*/pack.json

Type: JSON object

Used by: scripts/generate_manifest.py and the study-pack export pipeline

Common fields: display_name, topic, section_title_en, section_title_de, topic_en, grammar_focus_en, quiz_bucket, supports_sentences, merge_core_sentences, stage_options, default_quiz_modes

Feature-to-Data Mapping

Feature Main data file(s) Type Fields most relied on
Vocabulary vocabPath JSON array id, de, en, level, topic, part_of_speech/pos, categories, tags
Quiz word modes vocabPath JSON array id, de, en, accepted_answers, accepted_translations, level, stage, topic
Quiz sentence modes sentencePath plus optional core merge JSONL id, de, en, level, topics, target_vocab_id, vocab_ids
Reading passageGroups[*].packs[*].path JSON / JSONL chapter, section, title_de, title_en, passage_de, passage_en, questions[]
Builder sentenceBuilderPacks[*].path JSONL id, type, prompt, level, answer, tiles
Manifest data/generated/manifest.json JSON object core, revisionPacks, sentenceBuilderPacks, passageGroups
