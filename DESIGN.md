# Learning Web Design Principles

Learning Web is NOT a corporate SaaS dashboard.

It should feel like:
- a warm AI learning studio
- a storybook-inspired educational workspace
- a creative imagination lab
- a calm thinking environment

Avoid:
- generic startup aesthetics
- purple gradients
- cyberpunk AI visuals
- aggressive glassmorphism
- overly sharp enterprise UI
- dark fintech dashboards

Visual style:
- watercolor textures
- paper grain
- cinematic soft lighting
- warm pastel tones
- soft teal / cream / gold palette
- subtle floating doodles and idea clouds
- rounded organic shapes
- emotional and human atmosphere

Mascot usage:
- fox + girl mascot is central to the identity
- mascot should feel alive and integrated
- avoid placing mascot as a flat corner logo
- mascot may overlap containers slightly
- subtle glow behind mascot allowed
- mascot should guide the experience emotionally

Typography:
- elegant but friendly
- avoid overly technical fonts
- use soft serif for headings
- clean readable sans-serif for UI text

UI principles:
- reduce clutter
- increase breathing room
- clear visual hierarchy
- calm and readable
- emotionally warm
- educational not corporate

The product should feel like:
“a magical modern study desk powered by AI.”
