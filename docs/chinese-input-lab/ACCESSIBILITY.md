# Accessibility

- Semantic headings, buttons, labels and live feedback are used.
- Every key announces Latin key, Chinese root and explicit state.
- Key state includes text and border/shape treatment, not colour alone.
- The keyboard supports Tab, Enter/Space activation, touch and physical A–Z input.
- Modifier shortcuts and repeated keydown events are ignored; separate real presses preserve repeated roots.
- Focus indicators are visible and key touch targets remain usable on mobile.
- Layout scales without horizontal keyboard scrolling.
- Reduced-motion preferences disable transitions and transforms.
- Audio is user initiated, can be disabled and has a Jyutping/text fallback.

Manual screen-reader and 200% zoom checks remain release checklist items.
