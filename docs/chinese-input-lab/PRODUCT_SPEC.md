# Product specification

Audience: learners beginning Traditional Chinese keyboard input, especially Hong Kong learners using Cangjie or Quick.

Standard: Traditional Chinese, `zh-HK`, Cangjie version 5, Jyutping pronunciation metadata. Quick is the pinned Rime Quick 5 first/last-key standard and is evaluated separately.

The five configured stages are keyboard exploration, root recognition, character construction, whole-character analysis and typing challenge. A sixth lesson introduces Quick. Full Cangjie accepts 1–5 keys; Quick accepts 1–2 keys. The learner explicitly submits guided codes, so repeated roots such as `DD` are preserved and visible.

Success means a learner can discover the module, select a method, practise with touch or physical keys, receive method-aware feedback, inspect verified codes, retain progress after refresh and review weak/due characters.

Deferred: runtime AI explanations, speech grading, handwriting, Pinyin/stroke methods, cloud sync, arbitrary user lists and production mini games.
